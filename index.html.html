Bienvenidos al fascinante mundo de la programación

La programación es la habilidad fundamental que permite crear software, aplicaciones y soluciones digitales que impactan el mundo moderno.

Desde crear páginas web hasta desarrollar inteligencia artificial, la programación abre infinitas posibilidades.

¿Qué encontrarás en este sitio?

  • Características y usos de los lenguajes de programación más influyentes.
  • Explicaciones detalladas sobre herramientas y frameworks esenciales.
  • Tablas informativas, imágenes ilustrativas y enlaces útiles para aprender más.

Explora los principales lenguajes que están moldeando el desarrollo tecnológico actual, cada uno con sus paradigmas y usos distintivos.

Herramientas y Frameworks Fundamentales

El entorno de desarrollo y las herramientas que elijas impactan directamente en tu productividad y calidad de código.

Veamos algunas de las herramientas y frameworks más usados:

  • Visual Studio Code: Editor de código altamente personalizable con gran soporte de extensiones.
  • Git y GitHub: Sistemas para el control de versiones y colaboración en proyectos.
  • React: Biblioteca JavaScript para construir interfaces de usuario interactivas y reactivas.
  • Django: Framework de alto nivel para Python, enfocado en el desarrollo rápido y seguro de aplicaciones web.
  • Docker: Plataforma para desarrollar, enviar y ejecutar aplicaciones dentro de contenedores ligeros y portables.

Dominar estas herramientas te permitirá crear proyectos modernos, eficientes y escalables adaptados a las demandas actuales del mercado.

        // Navegación para mostrar/ocultar páginas
        const navLinks = document.querySelectorAll('.nav-link');
        const pages = document.querySelectorAll('section.page');

        navLinks.forEach(link => {
            link.addEventListener('click', e => {
                e.preventDefault();
                const page = link.getAttribute('data-page');
                if (!page) return;

                navLinks.forEach(nav => nav.classList.remove('active'));
                link.classList.add('active');

                pages.forEach(section => section.classList.remove('active'));
                const target = document.getElementById(page);
                if (target) target.classList.add('active');

                window.scrollTo({top: 0, behavior: 'smooth'});
            });
        });

        // Internal links inside pages (like "volver al inicio")
        document.querySelectorAll('.internal-link').forEach(link => {
            link.addEventListener('click', e => {
                e.preventDefault();
                const page = link.getAttribute('data-page');
                if (!page) return;

                navLinks.forEach(nav => {
                    nav.classList.toggle('active', nav.getAttribute('data-page') === page);
                });

                pages.forEach(section => section.classList.remove('active'));
                const target = document.getElementById(page);
                if (target) target.classList.add('active');

                window.scrollTo({top: 0, behavior: 'smooth'});
            });
        });

        // Accessibility: Dropdown keyboard support for Equipo menu
        const menuTeam = document.getElementById('menu-team');
        const submenuTeam = document.getElementById('submenu-team');

        menuTeam.addEventListener('keydown', (e) => {
            if (e.key === "Enter" || e.key === " " || e.key === "ArrowDown") {
                e.preventDefault();
                const expanded = menuTeam.getAttribute('aria-expanded') === 'true';
                menuTeam.setAttribute('aria-expanded', String(!expanded));
                if (!expanded) {
                    submenuTeam.querySelector('a').focus();
                } else {
                    menuTeam.focus();
                }
            } else if (e.key === "Escape") {
                menuTeam.setAttribute('aria-expanded', 'false');
                menuTeam.focus();
            }
        });

        submenuTeam.querySelectorAll('a').forEach((item, idx, list) => {
            item.addEventListener('keydown', (e) => {
                if (e.key === "ArrowDown") {
                    e.preventDefault();
                    let nextIdx = (idx + 1) % list.length;
                    list[nextIdx].focus();
                } else if (e.key === "ArrowUp") {
                    e.preventDefault();
                    let prevIdx = (idx - 1 + list.length) % list.length;
                    list[prevIdx].focus();
                } else if (e.key === "Escape") {
                    menuTeam.setAttribute('aria-expanded', 'false');
                    menuTeam.focus();
                }
            });
        });
    </script>
